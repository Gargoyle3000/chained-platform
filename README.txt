CHAINED DESIGN SYSTEM V0.1

OPENEN
1. Pak de zip uit.
2. Open index.html in je browser.
3. Handiger: open de map in VS Code en gebruik Live Server.

AANPASSEN
- De belangrijkste instellingen staan bovenaan styles.css onder :root.
- Verander daar kleur, lettergroottes, marges en maximale beeldbreedtes.
- Cascadia Code wordt lokaal geladen wanneer het op je computer staat.
- Alle onderdelen zijn echte HTML/CSS-componenten, geen afbeelding.

BESTANDEN
- index.html   inhoud en componenten
- styles.css  volledige vormgeving
- script.js   interactieve Archive-tags en zoekfunctie
- assets/     tijdelijke SVG-beelden

ARCHIVE
- Klik meerdere tags aan.
- De filtering gebruikt AND-logica: een werk moet aan alle actieve tags voldoen.
- CLEAR ALL herstelt het volledige archief.

VOLGENDE STAP
Vervang de tijdelijke SVG-beelden door echte kunstwerken en pas daarna de
verhoudingen in styles.css aan.
